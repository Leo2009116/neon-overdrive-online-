# 🎮 NEON OVERDRIVE ONLINE

2.5D 霓虹星區建造 × DIY 彈幕生存 × **多人團隊對戰**

## 🌐 免費聯機方案（APK / 網頁互通）
- 使用 **PeerJS**（開源 WebRTC P2P）＋ **官方免費公共信令伺服器**（`0.peerjs.com`）
- 網頁版與 APK 使用同一套代碼、同一個 PeerJS 伺服器 → **完全互通**
- 無需部署伺服器、無月費、無帳號

### 玩法
1. 主選單 → 🌐 聯機對戰 → **創建房間**（產生 6 位房間碼）
2. 其他玩家 → **加入房間**（輸入房間碼）
3. 選擇陣營（🔴紅隊 / 🔵藍隊）
4. 主機點擊 **開始對戰**
5. 場地會隨機生成 **圓形障礙物**（可阻擋子彈與玩家）
6. 擊毀敵方玩家得分，先到 10 分或限時結束獲勝
